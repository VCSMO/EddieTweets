# Eddie Tweets

Tweet carousel + 9:16 video builder.

- **Carousel format** — PNG slides at 1080×1440 (3:4)
- **Single Tweet format** — 7-second silent MP4 at 1080×1920 (9:16), ready for Reels / TikTok / Shorts

Built with Flask + Pillow + CairoSVG, with ffmpeg for MP4 export.
